# CORE//BREAKER

**Жанр:** 2D arena-survivor / top-down smasher
**Платформа:** браузер, клавиатура и touch
**Формат:** одна арена, бесконечные волны, короткие решения по сборке

## Концепт

Игрок управляет автономным боевым ядром внутри замкнутой реакторной арены. Волны дронов идут со всех сторон. Ядро автоматически наводится на ближайшую цель и выпускает энергетические импульсы, поэтому мастерство игрока — движение, дистанция и выбор безопасного маршрута к опыту.

За уничтожение врагов выпадают кристаллы опыта. При повышении уровня игра ставится на паузу и предлагает три обычных модуля. Каждая десятая волна вызывает Бастиона — тяжёлого босса с большим запасом здоровья и усиленным уроном при контакте. После победы он оставляет эпический модуль: игрок подбирает трофей и выбирает один из трёх сильных эффектов.

Забег заканчивается, когда здоровье ядра падает до нуля. Рекорд по достигнутой волне сохраняется локально.

## Игровой цикл

1. Уклоняйся от преследующих дронов: ядро автоматически атакует ближайшего.
2. Подбирай опыт, пока кристаллы притягиваются к игроку.
3. На новом уровне выбери один из трёх модулей.
4. Каждую десятую волну победи Бастиона и забери эпический модуль.
5. Продержись как можно дольше и побей рекорд волны.

## Направления сборки

- **Импульс:** урон, скорость стрельбы и пробивание нескольких целей.
- **Мобильность:** скорость перемещения и радиус сбора опыта.
- **Выживание:** запас здоровья, лечение и восстановление после босса.

Обычные улучшения дают небольшие постоянные приросты. Эпические усиливают специализацию: цепная молния пробивает толпу, красная зона ускоряет атаки, сердце титана полностью восстанавливает корпус.

## Управление

- `WASD` или стрелки — движение.
- `Esc` или кнопка «Пауза» — пауза.
- На сенсорном экране — нажми и удерживай направление движения.
- Импульсы выпускаются автоматически по ближайшему врагу.

## Запуск

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run build
```

## В текущем прототипе

- арена с ограниченными границами и движением с клавиатуры или touch;
- три базовых типа противников и босс каждой десятой волны;
- автоматическая атака, опыт, уровни и выбор модулей;
- эпический дроп босса, здоровье, пауза и повторный забег;
- рекорд по волне в `localStorage`;
- графика из геометрических форм Phaser без внешних ассетов.

## Следующая итерация
