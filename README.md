# Star Runner

Простая браузерная мини-игра в стиле arcade: игрок управляет синим квадратом, собирает жёлтые звёзды и избегает красных ловушек.

Цель — набрать 8 очков за 30 секунд, не потеряв все жизни. Игра понятна без объяснения и рассчитана на короткие, повторяемые раунды.

## Управление

- Стрелки или WASD — движение.
- R — перезапуск после поражения или победы.

## Игровой цикл

1. Игрок перемещается по полю.
2. Нужно собирать звёзды.
3. Красные блоки двигаются по арене и бьют по игроку.
4. При столкновении теряется жизнь.
5. Если время заканчивается или жизни исчерпаны — игра заканчивается.
6. При наборе 8 очков игрок побеждает.

## Запуск

```bash
npm install
npm run dev
```

Обычно проект открывается на:

```text
http://localhost:5173/
```

## Проверка сборки

```bash
npm run build
```

Если сборка проходит, проект готов к предпросмотру или публикации.
